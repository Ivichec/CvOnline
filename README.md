# CvOnline - CV Online con Angular

## Descripción

Proyecto de CV/portafolio online desarrollado con Angular. Sin backend necesario en principio; si se requiere en el futuro, se utilizará Spring Boot (Java).

---

## Tareas del proyecto

### 1. Configuración inicial
- [ ] Crear proyecto Angular con Angular CLI
- [ ] Configurar estructura de carpetas (components, models, services, assets)
- [ ] Configurar estilos globales y tema de colores
- [ ] Añadir fuentes e iconos (Google Fonts, Font Awesome / Material Icons)
- [ ] Configurar routing básico

### 2. Diseño y maquetación
- [ ] Definir diseño general / layout (responsive)
- [ ] Crear componente de navegación (navbar / sidebar)
- [ ] Crear componente de footer

### 3. Secciones del CV
- [ ] **Header / Hero**: Foto, nombre, título profesional y datos de contacto
- [ ] **Sobre mí**: Resumen profesional / biografía
- [ ] **Experiencia laboral**: Lista de puestos con empresa, fechas y descripción
- [ ] **Formación académica**: Estudios, títulos y certificaciones
- [ ] **Habilidades técnicas**: Lenguajes, frameworks, herramientas (con barras de progreso o tags)
- [ ] **Proyectos destacados**: Portafolio de proyectos con enlaces a repositorios/demos
- [ ] **Idiomas**: Nivel de idiomas
- [ ] **Contacto**: Formulario de contacto o enlaces a redes sociales / email

### 4. Datos del CV
- [ ] Crear modelo de datos (interfaces TypeScript) para cada sección
- [ ] Almacenar los datos en archivos JSON o constantes TypeScript
- [ ] Crear servicio Angular para cargar los datos del CV

### 5. Funcionalidades extra
- [ ] Modo oscuro / claro (toggle)
- [ ] Animaciones y transiciones suaves
- [ ] Botón para descargar CV en PDF
- [ ] Soporte multiidioma (i18n) - Español / Inglés
- [ ] SEO básico y meta tags

### 6. Testing y calidad
- [ ] Tests unitarios de componentes principales
- [ ] Verificar accesibilidad (a11y)
- [ ] Validar responsive en distintos dispositivos

### 7. Despliegue
- [ ] Configurar build de producción
- [ ] Desplegar en GitHub Pages / Vercel / Netlify
- [ ] Configurar dominio personalizado (opcional)

### 8. Backend con Spring Boot (solo si es necesario)
- [ ] API REST para formulario de contacto (envío de emails)
- [ ] Posible gestión dinámica de contenido del CV

---

## Tecnologías

- **Frontend**: Angular, TypeScript, HTML5, CSS3 / SCSS
- **Backend (opcional)**: Spring Boot, Java
- **Despliegue**: GitHub Pages / Vercel / Netlify
